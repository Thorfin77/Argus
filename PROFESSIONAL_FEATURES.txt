5. DETECTION TYPES EXPLAINED
   
   TCP TRAFFIC:
   - Shows: Source:Port → Destination:Port
   - Shows: Raw TCP payload data
   - Useful for: Chat apps, custom protocols
   
   HTTP REQUESTS:
   - Shows: Host, Path, Method (GET/POST)
   - Shows: Request data and headers
   - Useful for: Web browsing, API calls
   
   DNS QUERIES:
   - Shows: Domain names being looked up
   - Shows: Query type and response
   - Useful for: Website visits, DNS exfiltration
   
   IP TRAFFIC:
   - Shows: All IP-level traffic matching victim
   - Filters traffic to only victim IP
   - Useful for: General network monitoring

USAGE WORKFLOW:
==============

1. SELECT INTERFACE
   - Choose your network adapter
   - Must have valid IP (not 127.0.0.1)

2. SCAN NETWORK
   - Click "🔍 Scan Network"
   - Wait for results (cyan text)
   - See detected hosts in green
   - Network map updates with topology

3. SETUP ATTACK
   - Enter Target IP
   - Enter Gateway IP
   - View detected info in magenta

4. CONFIGURE DETECTION
   - Check which packets to monitor
   - TCP - All connections
   - HTTP - Only web traffic
   - DNS - Domain lookups
   - IP - Everything

5. START SPOOF & SNIFF
   - Click "⚡ Start ARP Spoof" (turns to stop button)
   - Click "📡 Start Sniffing" with filters enabled
   - Monitor log for detections (magenta)
   - Watch for colored messages:
     ✓ Yellow = Important events
     ✓ Red = Errors or attacks
     ✓ Green = Success
     ✓ Magenta = Detections

6. MONITOR OUTPUT
   - All timestamps with [HH:MM:SS]
   - Color indicates type:
     Red = Error/Critical
     Yellow = Warning/Important
     Green = Success
     Magenta = Detection!
     Cyan = Info

FEATURE COMBINATIONS:
===================

Detect Web Browsing:
- Enable: HTTP, DNS, IP
- Disable: TCP
- See: Websites visited, URLs browsed

Detect Chat Messages:
- Enable: TCP, IP
- Disable: HTTP, DNS
- See: Chat connections and data

Detect All Network Activity:
- Enable: All filters
- See: Everything on network

TROUBLESHOOTING:
===============

Colors not showing?
→ Check that matplotlib is installed
→ Restart the application

Detection filters not working?
→ Make sure you set them BEFORE clicking Start Sniffing
→ Check the log for "Filters enabled" message

No hosts detected?
→ Make sure gateway IP is correct
→ Run as Administrator
→ Select correct network interface
