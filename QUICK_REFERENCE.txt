🎯 ATTACK WORKFLOW
══════════════════════════════════════════════════════════════════════
1. Select Interface    → Choose network card
2. Scan Network        → Discover hosts (see 🟣 magenta)
3. Enter Target IP     → From scanned hosts
4. Enter Gateway IP    → Usually 192.168.1.1
5. Check Filters       → Select what to detect
6. Start ARP Spoof     → Begin attack (⚡ button)
7. Start Sniffing      → Capture packets (📡 button)
8. Monitor Log         → Watch for 🟣 DETECTIONS!
9. Stop                → Click ⏹️ buttons
