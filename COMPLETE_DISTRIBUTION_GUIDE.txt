═══════════════════════════════════════════════════════════════════════════
                    DEFENDER FALSE POSITIVE RESOLUTION
═══════════════════════════════════════════════════════════════════════════

IF WINDOWS DEFENDER QUARANTINES THE FILE:

User Steps (from WINDOWS_DEFENDER_GUIDE.txt):

METHOD 1: Windows Defender Settings GUI
────────────────────────────────────────
1. Open Windows Security
2. Go to "Virus & threat protection"
3. Click "Manage settings"
4. Add exclusion for file or folder
5. File is now whitelisted

METHOD 2: PowerShell (Administrator)
─────────────────────────────────────
Run in PowerShell as admin:

Add-MpPreference -ExclusionPath "C:\path\to\MITM"

METHOD 3: Microsoft Submission
──────────────────────────────
1. Visit: https://www.microsoft.com/wdsi/filesubmission
2. Upload the file
3. Include: SECURITY_ANALYSIS.txt
4. Explain: Educational software
5. Microsoft reviews and whitelists if confirmed false positive
