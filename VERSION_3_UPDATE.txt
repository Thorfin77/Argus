      - DNS QUERIES detected
      - Use this to see what was found!
   
   🔵 CYAN (#00ffff)
      - General information

      - Network details

   📅 TIMESTAMPS
      Each message includes [HH:MM:SS] for tracking

🎯 DETECTION FILTERS (NEW FEATURE!)
   Control exactly what the sniffer detects:
   
   ☑️ TCP TRAFFIC
      Shows: Source IP:Port → Dest IP:Port
      Shows: Payload data
      Detects: Chat applications, connections, data transfers
   
   ☑️ HTTP REQUESTS  
      Shows: Host, Path, Method (GET/POST)
      Shows: Request headers and data
      Detects: Web browsing, API calls
   
   ☑️ DNS QUERIES
      Shows: Domain names being looked up
      Shows: Query types and responses
      Detects: Websites visited
   
   ☑️ ALL IP TRAFFIC
      Shows: All IP-level packets
      Filters to victim IP automatically
      Detects: General network activity

   💡 TIP: Enable filters BEFORE clicking "Start Sniffing"

🚀 HOW TO USE THE NEW FEATURES
   
   1. Launch Application as Administrator
      
   2. Select Network Interface
      - Choose from dropdown
      - Auto-detects valid interfaces
      - Can't scan without this
   
   3. Scan Network
      - Click "🔍 Scan Network" button
      - Watch log for messages:
        • Cyan [*] = status updates
        • Magenta [+] = hosts found (THE IMPORTANT ONES!)
        • Green [✓] = scan complete
      - Results appear in green text table
      - Network map visualizes topology
   
   4. Select Target & Gateway
      - Click host in table OR type IP
      - Enter Gateway IP (usually 192.168.1.1)
      - Verify in cyan information messages
   
   5. Configure Detection Filters
      - Check boxes for what to monitor:
        ☑ TCP Traffic
        ☑ HTTP Requests
        ☑ DNS Queries
        ☑ IP Traffic
      - At least one must be checked
   
   6. Start ARP Spoof
      - Click "⚡ Start ARP Spoof" button
      - Watch log for magenta [+] target info
      - See yellow [*] packet counts
      - Attack is active when button shows "⏹️ Stop"
   
   7. Start Packet Sniffing
      - Click "📡 Start Sniffing" button
      - Log shows cyan [*] enabled filters
      - Watch for MAGENTA lines = packets detected!
      - Each detected packet shows:
        ✓ Type: [TCP], [HTTP REQUEST], [DNS]
        ✓ Timestamp: [HH:MM:SS]
        ✓ Details: Hosts, ports, data
   
   8. Monitor for Detections
      - 🟣 MAGENTA = Packet was detected!
      - 🔴 RED = Error occurred
      - 🟡 YELLOW = Important status
      - 🟢 GREEN = Success
      - 🔵 CYAN = Information
   
   9. Stop Operations
      - Click "⏹️ Stop ARP Spoof" to stop attack
      - Click "⏹️ Stop Sniffing" to stop capture
      - ARP tables automatically restored
      - See green [✓] success message
