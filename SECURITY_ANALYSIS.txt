═══════════════════════════════════════════════════════════════════════════
                         NETWORK OPERATIONS ANALYSIS
═══════════════════════════════════════════════════════════════════════════

OPERATION 1: Network Scanning
───────────────────────────────────────────────────────────────────────────
What it does: Sends ARP requests to discover hosts
Why: Educational understanding of network discovery
How visible: All discovered hosts shown in GUI
Is it destructive: NO - Only queries
Authorization needed: NO - Standard network scanning
Risk: LOW - Same as "ping" command
Educational value: HIGH - Shows network discovery techniques
Detection: Visible network traffic (ARP requests)

OPERATION 2: ARP Spoofing
───────────────────────────────────────────────────────────────────────────
What it does: Sends forged ARP replies to position between hosts
Why: Teach MITM attack mechanism
How visible: GUI shows all targeted hosts
Is it destructive: REVERSIBLE - Restores routing tables
Authorization needed: YES - Explicit authorization required
Risk: MEDIUM - Can disrupt network if misused
Educational value: HIGH - Shows how MITM works
Detection: Visible network traffic (ARP replies)

OPERATION 3: Packet Sniffing
───────────────────────────────────────────────────────────────────────────
What it does: Captures network packets passing through interface
Why: Teach packet analysis and protocol understanding
How visible: Decoded packets shown in GUI log
Is it destructive: NO - Passive observation
Authorization needed: YES - Network privacy
Risk: MEDIUM - Can capture sensitive data if misused
Educational value: HIGH - Shows protocol structures
Detection: Only active while UI shows "Sniffing..."

OPERATION 4: Data Extraction
───────────────────────────────────────────────────────────────────────────
What it does: Extracts HTTP responses and URLs from captured traffic
Why: Show why encryption is important
How visible: Displayed in GUI in real-time
Is it destructive: NO - Observation only
Authorization needed: YES - Data privacy
Risk: MEDIUM - Demonstrates vulnerability
Educational value: HIGH - Teaches importance of encryption
Detection: Only while sniffing is active
