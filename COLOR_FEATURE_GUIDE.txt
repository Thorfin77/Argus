📊 LOG COLOR LEGEND:
═════════════════════════════════════════════════════════════════════════════

🔴 RED (#ff4444) - ERRORS & CRITICAL
   Examples:
   [!] Scan error: Network unreachable
   [!] Could not resolve MAC addresses
   [!] Sniff error: Permission denied

🟡 YELLOW/ORANGE (#ffaa00) - WARNINGS & IMPORTANT
   Examples:
   [*] Using interface: Ethernet
   [*] Getting MAC addresses...
   [*] Starting ARP spoof...
   [*] Filters enabled - TCP: True, HTTP: True

🟢 GREEN (#44ff44) - SUCCESS
   Examples:
   [✓] Scan complete: 5 hosts discovered
   [✓] ARP spoof stopped and tables restored
   [+] Sniffing on Ethernet for victim 192.168.1.100

🟣 MAGENTA (#ff0088) - DETECTIONS (CRITICAL!)
   Examples:
   [+] HOST FOUND: 192.168.1.50 → AA:BB:CC:DD:EE:FF
   [TCP] 192.168.1.50:49152 → 8.8.8.8:53
   [HTTP REQUEST] DETECTED!
   [DNS] QUERY DETECTED!

🔵 CYAN (#00ffff) - INFORMATION
   Examples:
   [*] Interface IP: 192.168.1.100
   [*] Network: 192.168.1.0/24
   [*] Sending ARP requests...

🚀 TYPICAL ATTACK SEQUENCE:
═════════════════════════════════════════════════════════════════════════════

Step 1: SELECT INTERFACE
   └─ Choose from dropdown (Ethernet, Wi-Fi, etc.)

Step 2: SCAN NETWORK
   └─ Click 🔍 Scan Network
   └─ Log shows [*] messages (cyan) during scan
   └─ Magenta [+] for each host found
   └─ Green [✓] when complete

Step 3: CONFIGURE ATTACK
   └─ Enter Target IP from discovered hosts
   └─ Enter Gateway IP (usually 192.168.1.1)
   └─ Network map updates with topology

Step 4: ENABLE FILTERS
   └─ Check detection types you want
   └─ At least one filter should be enabled
   └─ Ready to capture traffic

Step 5: START ARP SPOOF
   └─ Click ⚡ Start ARP Spoof
   └─ Log shows magenta [+] for target/gateway
   └─ Yellow [*] for packet counts
   └─ You're now intercepting traffic

Step 6: START SNIFFING
   └─ Click 📡 Start Sniffing
   └─ Log shows cyan [*] with enabled filters
   └─ Watch for magenta detections!
   └─ Each detected packet shown with timestamp

Step 7: MONITOR OUTPUT
   └─ Red = Errors (something went wrong)
   └─ Yellow = Important events
   └─ Green = Success
   └─ Magenta = Packet detected! (action happened)

Step 8: STOP
   └─ Click ⏹️ buttons to stop
   └─ ARP tables automatically restored
   └─ Green [✓] success message
