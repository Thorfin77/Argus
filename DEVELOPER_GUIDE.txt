LAYERED ARCHITECTURE:
```
┌─────────────────────────────────────────┐
│    Presentation Layer (PySide6 GUI)     │
│  - Main window, buttons, tables          │
│  - Log widget, network map               │
└─────────────────────────────────────────┘
           ↑                    ↓
    Signals (log)        Qt Events
           ↓                    ↑
┌─────────────────────────────────────────┐
│    Business Logic Layer (QObject)       │
│  - NetworkScanner class                  │
│  - ARPSpoofer class                      │
│  - PacketSniffer class                   │
└─────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────┐
│    Network Layer (Scapy)                │
│  - ARP requests/replies                  │
│  - Packet crafting                       │
│  - Packet sniffing                       │
└─────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────┐
│    System Layer                         │
│  - Raw sockets (requires admin)          │
│  - Network interfaces                    │
│  - System information (psutil)           │
└─────────────────────────────────────────┘
```

DATA FLOW:
```
User Action → GUI Signal → Business Logic → Network Operation → Display Result
  (Button)   (emit)       (Scanner/Spoof)  (Scapy)           (Log + Table)
```

THREADING MODEL:
```
Main GUI Thread (Qt Event Loop)
    ├─ Scanner Worker Thread
    │   └─ ARP scanning
    │   └─ Emit log signals
    │
    ├─ Spoofer Worker Thread
    │   └─ ARP packet sending
    │   └─ Emit log signals
    │
    └─ Sniffer Worker Thread
        └─ Packet capture loop
        └─ Emit log signals
```

🔄 WORKFLOW LOGIC
═══════════════════════════════════════════════════════════════════════════════

COMPLETE ATTACK WORKFLOW:

Step 1: SELECT INTERFACE
  User: Click dropdown → Select "Ethernet"
  System: Store selected interface name

Step 2: SCAN NETWORK
  User: Click "🔍 Scan Network" button
  System:
    ├─ Create NetworkScanner instance
    ├─ Call scan(interface_name)
    ├─ Spawn worker thread
    └─ Worker thread:
        ├─ Get interface IP
        ├─ Get netmask
        ├─ Calculate network range
        ├─ Send ARP to all IPs
        ├─ Parse replies
        ├─ Emit log signals
        ├─ Emit finished signal
        └─ UI populates table
  
  Result:
    - Log shows host discoveries (magenta)
    - Table shows IP and MAC
    - Network map updates with hosts

Step 3: SETUP ATTACK
  User:
    ├─ Enter Target IP (e.g., 192.168.1.100)
    ├─ Enter Gateway IP (e.g., 192.168.1.1)
    └─ Click "⚡ Start ARP Spoof"
  
  System:
    ├─ Validate IPs provided
    ├─ Create ARPSpoofer instance
    ├─ Call start_spoof(target, gateway, iface)
    ├─ Spawn worker thread
    └─ Worker thread:
        ├─ Get victim MAC (ARP)
        ├─ Get gateway MAC (ARP)
        ├─ Get attacker IP/MAC
        ├─ Loop: Send forged ARP packets
        │  ├─ Victim: "I am gateway"
        │  └─ Gateway: "I am victim"
        └─ Emit log signals continuously
  
  Result:
    - Log shows target/gateway (magenta)
    - Button changes to "⏹️ Stop ARP Spoof"
    - Attacker is now MITM (traffic flows through)

Step 4: CONFIGURE FILTERS
  User:
    ├─ Check "TCP Traffic"
    ├─ Check "HTTP Requests"
    ├─ Uncheck "DNS Queries"
    └─ Uncheck "All IP Traffic"
  
  System:
    └─ Stores filter preferences

Step 5: START SNIFFING
  User:
    ├─ Enter Victim IP
    └─ Click "📡 Start Sniffing"
  
  System:
    ├─ Create PacketSniffer instance
    ├─ Call set_detection_filters(...) with settings
    ├─ Call start_sniff(iface, victim_ip)
    ├─ Spawn worker thread
    └─ Worker thread:
        ├─ Loop: Capture packets
        │  ├─ Check destination/source is victim
        │  ├─ Check enabled filters
        │  ├─ Parse packet layers
        │  ├─ Extract relevant data
        │  └─ Emit log signal (magenta for detection)
        └─ Continue until stop_sniff() called
  
  Result:
    - Log shows TCP connections (magenta)
    - Log shows HTTP requests (magenta)
    - Payloads shown in yellow
    - Real-time detection alerts

Step 6: MONITOR DETECTIONS
  Watch for 🟣 MAGENTA lines in log:
    - [TCP] connection details
    - [HTTP REQUEST] with host/path
    - [DNS] query details
    - Payload data

Step 7: STOP OPERATIONS
  User:
    ├─ Click "⏹️ Stop ARP Spoof"
    └─ Click "⏹️ Stop Sniffing"
  
  System:
    ├─ ARPSpoofer:
    │  ├─ Set is_running = False
    │  ├─ Send legitimate ARP packets 10 times
    │  ├─ Restore victim's real gateway ARP
    │  └─ Restore gateway's real victim ARP
    │
    └─ PacketSniffer:
       ├─ Set is_running = False
       └─ Stop packet capture
  
  Result:
    - Network restored to normal
    - All threads cleanly exit
    - Success messages (green)
    - Ready for new operations

🔧 TROUBLESHOOTING FOR DEVELOPERS
═══════════════════════════════════════════════════════════════════════════════

COMMON DEVELOPMENT ISSUES:

Issue: "Scapy not working"
Solution:
  ├─ Check admin privileges
  ├─ Verify scapy installed: pip install scapy
  ├─ Check network drivers
  └─ Try: python -c "import scapy; print(scapy.__version__)"

Issue: "GUI not responsive"
Solution:
  ├─ Check threading is used
  ├─ Check daemon=True on threads
  ├─ Verify signals are emitted
  └─ Check main thread isn't blocked

Issue: "Signals not working"
Solution:
  ├─ Check class inherits QObject
  ├─ Check Signal is defined at class level
  ├─ Verify connect() is called
  └─ Check signal parameters match slot

Issue: "Packets not captured"
Solution:
  ├─ Check interface is correct
  ├─ Check victim IP is correct
  ├─ Verify ARP spoof is running
  ├─ Check filters are enabled
  └─ Try different interface
